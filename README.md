# Ditaí

Ditado por voz com IA para Windows. Aperte o atalho em qualquer caixa de texto,
fale, aperte de novo — o texto aparece limpo e pontuado.

## Baixar

**[⬇ Baixar o Ditaí para Windows](../../releases/latest/download/Ditai-Setup.exe)**

## Como usar

1. Instale e abra o Ditaí. Na primeira vez ele pede uma chave gratuita da Groq.
2. Clique em qualquer caixa de texto (WhatsApp, Gmail, navegador...).
3. Aperte o atalho (padrão: F9), fale e aperte de novo.

O Ditaí fica no ícone do microfone perto do relógio. Clique nele para mudar
as configurações ou sair.
